# PayO Admin Portal

A standalone KYC verification admin portal for the PayO digital wallet app.

## Features
- 📊 **Dashboard** — Live stats, KYC overview donut chart, recent activity
- ✅ **KYC Review** — Approve/reject KYC with document review modal
- 👥 **Users** — Full user management with profile modal
- 💰 **Wallets** — Wallet monitoring with lock/unlock controls
- 📈 **Analytics** — Charts, trends, rejection reasons
- 📋 **Audit Log** — Complete admin action history
- 🔔 **Notifications** — Real-time notification centre

## Tech Stack
- React JS
- React Router DOM
- Pure CSS (no component libraries)

## Run Locally

```bash
npm install
npm start
```

## Deploy to GitHub Pages

1. Update `homepage` in `package.json` with your GitHub username
2. Run:
```bash
npm run deploy
```

## Build for Production
```bash
npm run build
```
